# Brazzom Video Landing Page

## Files
- `index.html` — landing page
- `style.css` — responsive black/blue neon design
- `script.js` — Monetag link and optional video URL
- `assets/video-poster.svg` — blurred placeholder poster

## Setup
1. Download and extract the ZIP.
2. Open `script.js`; the Monetag link is already set to `https://uplcm.com/4/11706929`.
3. Add a direct MP4 URL to `VIDEO_URL` for a video you own or are authorized to share.
4. Upload all files and the `assets` folder to the root of your GitHub repository.
5. Open **Settings → Pages → Deploy from a branch**, choose `main` and `/ (root)`, then save.

The sponsored link is clearly labelled and optional. This static page does not verify ad engagement. Do not put secret keys in client-side code.
